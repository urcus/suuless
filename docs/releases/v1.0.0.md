# SuuLess v1.0.0 — First stable release

SuuLess 1.0.0 is the first stable release of our self-hosted cigarette consumption tracker, formerly known as Stop Clop. Keep your data on your own server and access it from the web or the Android app.

## Included in this release

- Cigarette tracking, statistics, historical costs, currencies and time zones.
- Personal journeys, goals, craving pauses and reminders.
- English, French and Japanese interfaces.
- Android application and home-screen widget, with server synchronization.
- Account administration, invitations and SMTP configuration.
- Docker Compose and Kubernetes deployment examples, plus an OpenAPI contract.
- Container images for AMD64 and ARM64, including Raspberry Pi running a 64-bit OS.

## Getting started

Read the [Docker guide](https://github.com/urcus/suuless/blob/v1.0.0/docs/deployment/docker.md), [Kubernetes guide](https://github.com/urcus/suuless/blob/v1.0.0/docs/deployment/kubernetes.md), [Android guide](https://github.com/urcus/suuless/blob/v1.0.0/docs/user-guide/android.md) or the [full documentation](https://github.com/urcus/suuless/blob/v1.0.0/docs/README.md). Integrations can use the [OpenAPI contract](https://github.com/urcus/suuless/blob/v1.0.0/docs/api/openapi.yaml).

Back up your existing database before upgrading. Use HTTPS when exposing an instance beyond your local network.
