# SuuLess v1.0.1 — Consumption exports and administrator initialization fix

## Consumption exports on web and Android

- Open **Analysis** or **History → Export / share**, then choose the last **7, 30 or 90 days**, including today in your account's time zone.
- Download or share a **CSV** containing individual consumption entries and historical costs.
- Download or share a **consumption report** with period totals, daily averages, costs by currency and daily figures. The self-contained HTML report can be opened in a browser and printed or saved as PDF, for example to discuss with a tobacco cessation specialist.
- Reports contain no account name or identifier. Days without entries are clearly distinguished from confirmed days without smoking; currencies remain separate.
- Android supports the system save picker and share sheet. Web sharing uses supported browsers, with a download fallback. Interfaces and reports support English, French and Japanese.

## Fix: first administrator on an existing database

`ADMIN_USERNAME` and `ADMIN_PASSWORD` can now create a dedicated first administrator when a database already contains ordinary users but has no administrator. Historical account-initialization markers no longer prevent this.

Creation remains transactional and safe across concurrent startup workers. Existing users, passwords, sessions and consumption records are preserved. Existing administrators are not reset or recreated. A username already belonging to an ordinary user is rejected instead of silently promoting that account: configure a distinct administrator username.

Back up the database before upgrading. See the [administrator setup guide](https://github.com/urcus/suuless/blob/v1.0.1/docs/deployment/administration.md) for configuration and recovery procedures.
