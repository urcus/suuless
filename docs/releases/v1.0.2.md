# SuuLess v1.0.2 — PostgreSQL support and automatic web updates

## Optional external PostgreSQL

- SQLite remains the default. Configure `DATABASE_URL` to use an external PostgreSQL database.
- The migration tool supports a dry run, verifies every copied row and preserves accounts, sessions, API keys, consumption history, currencies and settings. It requires an empty destination and never overwrites an existing installation.
- Follow the [PostgreSQL migration guide](https://github.com/urcus/suuless/blob/v1.0.2/docs/deployment/postgresql.md) before switching an existing installation. Changing `DATABASE_URL` alone does not migrate data. Back up SQLite and stop all writers for the final copy.

## Automatic web updates

The dashboard now refreshes every 10 seconds while visible and online, and when returning to the page or reconnecting. Statistics, history and settings reflect changes from other devices without pressing Refresh. Unsaved edits, manually selected entry timestamps and loaded history are preserved.

## iPhone shortcuts

Prepared **SuuLess +1** shortcuts and an [installation guide](https://github.com/urcus/suuless/blob/v1.0.2/docs/user-guide/iphone-shortcut.md) make it easier to record consumption from an iPhone shortcut or widget. Setup asks for your instance URL and personal API key. The [shortcut files](https://github.com/urcus/suuless/tree/v1.0.2/iphone) are distributed separately from the application image and Android builds.

## Fixes and diagnostics

- Improved SMTP submission logs without exposing credentials or message contents. The interface now distinguishes acceptance by the SMTP relay from confirmed inbox delivery.
- Updated the container's Alpine zlib requirement to `1.3.2-r1` or later to address CVE-2026-85091.
- Added PostgreSQL integration coverage to both CI systems, alongside the existing SQLite tests and security checks.
