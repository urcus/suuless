Trois accès, un historique par personne

L’API authentifie chaque requête et limite les données au compte associé à la clé.

Les clients utilisent HTTP en développement et HTTPS derrière un reverse proxy en production. Le proxy TLS est à fournir lors du déploiement. Le serveur sert également les fichiers de l’interface web. Le stockage SQLite n’est pas un conteneur séparé.
