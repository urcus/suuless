Un changement, un compteur rafraîchi

Après un ajout, une suppression ou un changement de réglages. Le téléphone reçoit un signal via ntfy, puis relit les données du compte dans l’API.

La file persiste dans le volume SQLite. Les erreurs sont réessayées avec délai croissant ; un changement survenant pendant un envoi reste en attente. Le rafraîchissement périodique du widget reste actif en secours.
