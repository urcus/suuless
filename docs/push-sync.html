STOP CLOP · SYNCHRONISATION INTÉGRÉE

Un seul serveur, une seule application

La connexion au compte configure le flux direct. Android demande les autorisations pour actualiser le widget en arrière-plan.

La révision persiste dans le volume SQLite. Après une coupure, l’application récupère le dernier état. La notification Android permet d’arrêter le service ; le widget conserve son rafraîchissement manuel et périodique.
